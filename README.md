#### How I work

- Build with the **end user in mind**, not the tech stack. Small businesses don't care about my architecture; they care that the thing works on a flaky internet connection at 11pm.
- Ship in **slices** — a working end-to-end MVP first, then iterate. Most of these repos went from idea → live in weeks, not months.
- Treat **data security and multi-tenancy** as design-time concerns, not retrofits. Postgres RLS, env vars, and minimal scope are the defaults.
